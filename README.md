# Haier — баннеры

Баннеры для сайта Haier. Вложенность папок — как в рабочих папках студии.

- `Haier/Banners/KolonnaBanner/v1/` — баннер «Соберите стирально-сушильную колонну», вариант 1: крупные машины, камера по сцене, сушилка и соединитель прилетают, соединение, отдаление.
- `Haier/Banners/KolonnaBanner/v2/` — тот же баннер, вариант 2: колонна целиком, листание стрелками.

Посмотреть: https://kapungas79.github.io/Haier/

Каждая папка — статичная страница: `index.html` показывает баннер на подложке страницы каталога (1920×1080, вписывается в окно). Сам баннер — блок `section.kb` (1312×243), его стили и скрипт (`banner*.css`, `banner*.js`) и папка `assets/`.
